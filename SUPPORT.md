# Support

Unified AI System is an open-source project maintained through public,
searchable channels.

## Questions And Ideas

Use [GitHub Discussions](https://github.com/happy520ai/unified-ai-system/discussions)
for setup questions, architecture conversations, ideas, and general feedback.

## Bugs

Use the
[bug report form](https://github.com/happy520ai/unified-ai-system/issues/new?template=bug_report.yml)
for reproducible defects. Include the operating system, Node.js and pnpm
versions, exact command, expected result, and sanitized logs.

## Security

Do not disclose vulnerabilities, credentials, private endpoints, or
authorization records in a public issue. Follow [SECURITY.md](SECURITY.md).

## Scope

Community support is best effort. The repository does not currently provide a
hosted public API, production certification, or a commercial support SLA.
