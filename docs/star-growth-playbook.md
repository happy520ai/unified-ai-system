# Star Growth Playbook

Last verified: 2026-08-09

This repo grows best when every public post is tied to a reproducible command and a concrete user result.
Keep the loop small: verify, publish, collect, improve.

## Operating Loop

- Daily: run `pnpm growth:campaign`, share one English and one Chinese or community post, ask for OS + output, and capture one result.
- Weekly: run `pnpm growth:feedback`, `pnpm growth:evidence-pack`, and `pnpm growth:sync-thread`, then refresh the evidence pack and checklist.
- Monthly: summarize what changed, what users reported, and one repo improvement shipped from feedback.

## Good Evidence

- command output
- OS or environment note
- screenshot or one-line result
- one follow-up fix
- one public link to the proof

## What To Avoid

- Do not claim AGI, L5, or production readiness.
- Do not turn the post into vague hype.
- Do not reuse an old proof unless there is new evidence.
